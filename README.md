# 🎉 Decorito – Decoration Marketplace

## 📌 Overview

People love celebrating every small and big moment in life, but it’s not always possible to be prepared with all the necessary decoration items in advance. **Decorito** solves this problem by providing quick and easy access to decoration products whenever you need them.

Decorito is a full-stack web application where users can **buy and sell decoration items** for various events such as birthdays, parties, and celebrations. Whether it’s a small occasion or a grand event, users can conveniently order decoration items and get them delivered quickly.

---

## 🚀 Features

* 🛍️ Buy and sell decoration items
* 🔐 Role-based access (User & Shopkeeper)
* 💳 Secure payments using Stripe
* 📦 Product listing and management
* 🔎 Easy browsing of products

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Payment Gateway:** Stripe

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/VedikaKulkarni/Decorito.git
cd Decorito
```

### 2. Install dependencies

```bash
# For backend
cd backend
npm install

# For frontend
cd ../frontend
npm install
```

### 3. Setup environment variables

Create a `.env` file in the backend folder and add:

```env
MONGO_URI=your_mongodb_connection
STRIPE_KEY=your_stripe_key
JWT_SECRET=your_secret_key
```

### 4. Run the project

```bash
# Run backend
cd backend
npm start

# Run frontend
cd frontend
npm start
```
